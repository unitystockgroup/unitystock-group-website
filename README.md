# UnityStock Group LLC Website
Responsive single-page static website. Includes a dedicated section explaining the company's emphasis on each brand's Minimum Advertised Price (MAP) policy and applicable marketplace pricing guidelines.

## Files
- `index.html` — page content
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation, reveal animations, automatic copyright year
- `assets/unitystock-group-logo.jpeg` — supplied logo

## Publish with GitHub Pages
1. Create a GitHub repository (for example `unitystock-group-website`).
2. Upload the contents of this folder to the repository root. `index.html` must be at the root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub will display the published Pages URL when deployment completes.

No framework, package installation, or build step is required. The email link opens the visitor's email app; there is no web form or visitor-data collection.

Before publishing, verify that the address and resale certificate number are approved for public display. MAP language describes the company's intent to follow applicable brand guidelines; it does not claim that UnityStock controls or enforces another seller's prices.
